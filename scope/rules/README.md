Project-owned rules for what the Boost skills do not cover (new releases, house conventions).
- _all.md: injected for every role.
- <vendor>__<package>.md (e.g. livewire__livewire.md): injected only when that package is in composer.lock, max 1500 chars each.
Where new rules come from: <<<GAP>>> sections and LESSON lines produced during sprints are listed in docs/agents/pm/<sprint>.md and in the run summary. Review them, then promote the good ones to a file here.
